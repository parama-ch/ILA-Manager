## 1. บทนำ
Integrated Logic Analyzer (ILA) ของ Vivado คือ IP มาตรฐานสำหรับตรวจจับสัญญาณภายในชิป FPGA ของ AMD/Xilinx แต่การไล่และกำหนดหมายเลข Probe ทีละพอร์ตเป็นเรื่องที่เสียเวลาและผิดพลาดได้ง่าย **ILA Manager** ออกแบบมาเพื่อช่วยลดขั้นตอนเหล่านี้ โดยให้วิศวกร FPGA สามารถลากไฟล์ HDL มาวาง เลือกสัญญาณ จัดการลำดับพอร์ต และสร้างโค้ด TCL กับ Port Map ให้อัตโนมัติ

---

## 2. การติดตั้งและเริ่มใช้งาน
ติดตั้ง `ila-manager` ผ่าน pip:
```bash
pip install git+https://github.com/parama-ch/ILA-Manager.git
```
เริ่มเปิดใช้งานโปรแกรม:
```bash
ila-manager
```
โปรแกรมจะเปิดเบราว์เซอร์และเข้าสู่หน้าต่างทำงานที่ `http://127.0.0.1:8765` โดยอัตโนมัติ

---

## 3. ภาพรวมของหน้าต่างโปรแกรม
หน้าจอโปรแกรมแบ่งออกเป็น 3 คอลัมน์ที่ทำงานสอดประสานกัน:
1. **คอลัมน์ซ้าย (HDL Sources & Signals)**: พื้นที่ลากไฟล์มาวาง ตัวเลือกโมดูลเป้าหมาย และรายชื่อสัญญาณที่แกะได้พร้อมตัวกรอง
2. **คอลัมน์กลาง (ILA Port Manager)**: แถบตั้งค่า ILA และตารางจัดการ Probe (การแมปสัญญาณ, ขนาดบิต, ประเภท Probe, ปุ่มเลื่อนและสลับตำแหน่ง)
3. **คอลัมน์ขวา (Generated Code)**: แสดงโค้ดแบบเรียลไทม์ ทั้ง Vivado TCL, VHDL Port Map และ Verilog พร้อมปุ่มคัดลอกและดาวน์โหลด

---

## 4. การจัดการไฟล์ HDL และการเลือกสัญญาณ
- ลากไฟล์ `.vhd`, `.vhdl`, `.v` หรือ `.sv` มาวางในกล่อง Drop Zone ทางด้านซ้าย
- ใช้เมนูดรอปดาวน์ **Target Module / Unit** เพื่อเลือกโมดูลที่ต้องการฝัง ILA
- ค้นหาสัญญาณด้วยช่อง Search หรือกดเลือกหมวดหมู่ **All**, **Ports** หรือ **Signals**

---

## 5. การจัดการพอร์ต ILA
### การเพิ่ม Probe
- กดปุ่ม `+` ที่แถวของสัญญาณในแผงซ้าย สัญญาณนั้นจะถูกเพิ่มต่อท้ายในตาราง Probe ทันที
- หรือลากการ์ดสัญญาณจากแผงซ้ายมาปล่อยลงในตารางแผงกลาง

### การจัดเรียงลำดับ Probe
- คลิกที่ไอคอน `⋮⋮` หน้าพอร์ตแล้วลากขึ้นหรือลงเพื่อเปลี่ยนลำดับ
- หรือกดปุ่มลูกศร `↑` และ `↓` ที่คอลัมน์ขวาสุดของแต่ละแถว

### การสลับตำแหน่ง Probe (Swap)
- **วิธีที่ 1**: กดปุ่ม **⇄ Swap Probes** บนแถบหัวข้อ เลือก Probe ตัวที่ 1 และตัวที่ 2 แล้วกดยืนยัน
- **วิธีที่ 2**: กดปุ่ม `⇄` บนแถวของ Probe ตัวที่ต้องการสลับ
- **วิธีที่ 3**: กดปุ่ม `Alt` ค้างไว้ แล้วลาก Probe ตัวหนึ่งไปวางทับ Probe อีกตัวหนึ่ง

### การตัดช่วงบิต (Bit Slicing) และการเลือกสมาชิกใน Array
- สำหรับสัญญาณประเภท Vector, Array หรือ Record ให้กดไอคอนกรรไกร `✂` หรือคลิกที่ชื่อสัญญาณในตาราง
- จะมีหน้าต่างขึ้นมาให้ระบุ:
  - ดัชนีของ Array (เช่น `2` สำหรับ `mem(2)`)
  - ฟิลด์ของ Record (เช่น `tdata`)
  - ช่วงบิตที่ต้องการ (เช่น `15 downto 8` หรือ `[7:0]`)

## 6. การตั้งค่า ILA Core
### Flip-Flop Pipeline Stages
ใน Vivado ค่าตั้งต้นของ `C_INPUT_PIPE_STAGES` จะถูกกำหนดไว้ที่ 1 ซึ่งสำหรับวงจรที่มีสัญญาณนาฬิกาความเร็วสูง การเดินสายสัญญาณระยะไกลจากจุดต่าง ๆ ของชิปเข้าสู่ ILA มักก่อให้เกิดปัญหา Timing Violation (Setup Slack ติดลบ)
**ILA Manager จึงกำหนดค่าเริ่มต้นไว้ที่ 4 ชั้น (Stages = 4)** เพื่อเพิ่ม Flip-Flop Retiming ให้การปิด Timing ใน Vivado ทำได้อย่างราบรื่น

### Sample Depth และ Trigger Match Units
- **Sample Depth**: เลือกขนาดความลึกของหน่วยความจำบันทึกสัญญาณได้ตั้งแต่ 1024 ถึง 65536 ตัวอย่าง
- **Trigger Match Units**:
  - *Same count for all*: กำหนดให้ทุกพอร์ตมีจำนวนตัวเปรียบเทียบเงื่อนไขทริกเกอร์เท่ากัน
  - *Individual per probe*: กำหนดจำนวนตัวเปรียบเทียบเงื่อนไขแยกอิสระในแต่ละพอร์ตได้ (1 ถึง 16 ชุด)

## 7. การนำไปใช้งานใน AMD Vivado
1. ที่แผงขวา เลือกแท็บ **Vivado TCL** แล้วกดปุ่ม **Copy**
2. ใน Vivado Tcl Console ให้วางคำสั่งหรือสั่งรัน:
   ```tcl
   source ila_0.tcl
   ```
3. คัดลอกโค้ดจากแท็บ **VHDL Port Map** หรือ **Verilog Port Map** ไปวางในโมดูลของคุณ
   - สำหรับ VHDL สัญญาณขนาด 1-bit จะถูกแมปเข้าเวกเตอร์อย่างถูกต้อง:
     ```vhdl
     probe0(0) => rx_valid,
     ```
   - ต่อตรงผ่าน Direct Entity Instantiation โดยไม่ต้องเขียน component:
     ```vhdl
     u_ila_0 : entity work.ila_0
     ```

## 8. การบันทึกโปรเจกต์ และระบบ Diff Review
- กดปุ่ม **Save Project** เพื่อบันทึกงานเป็นไฟล์ `.ilaproj` (JSON)
- เมื่อนำไฟล์โปรเจกต์นี้กลับมาเปิดใหม่หลังจากที่มีการแก้โค้ด HDL (เช่น บัสเดิม 8 บิตเปลี่ยนเป็น 16 บิต หรือสัญญาณถูกลบออกไป) หน้าต่าง **Diff Review** จะปรากฏขึ้นทันที:
  - **Update to new width**: ปรับขนาดบิตของ Probe ให้ตรงกับ HDL ใหม่ทันที
  - **Remap to suggestion**: แมปพอร์ตไปยังสัญญาณที่เปลี่ยนชื่อใหม่อัตโนมัติด้วยระบบตรวจจับความคล้ายคลึง
  - **Delete probe**: ลบ Probe ที่สัญญาณต้นฉบับไม่มีอยู่อีกต่อไป

## 9. การใช้งานผ่าน Command Line (CLI)
สร้างสคริปต์อัตโนมัติจากไฟล์โปรเจกต์:
```bash
ila-manager generate my_project.ilaproj --ila ila_0 --out ./build
```
แกะสัญญาณจากไฟล์ HDL เพื่อดูเป็น JSON:
```bash
ila-manager parse examples/sample_uart_rx.vhd
```
